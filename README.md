## Introduction  

- https://www.firebase.com  

Firebase, is another way to both *host/deploy* web sites.

It is a Google owned technology...; and, you need to *sign up* in order to use their online service;   
there are both FREE/and, too, paid for a/c's.  

Right now, I'm still *new* to using Firebase...;  
but, I believe ordinary users can use the service for FREE.  

My own personal experience so far to date is, one can build web sites using standard web page building technologies:    

- html  
- css  
- javascript  
- graphic files  
- etc.  

-----

## Example site  

This is my *own* Firebase site:  

- https://fb01-c433c.web.app

- You can link to a GitHub repository to automatically *store/deploy* the code:        
- https://www.github.com/pramnora/Firebase   
- It is also possible to use Git to both *pull/push* changes to the site from off your local home computer.
